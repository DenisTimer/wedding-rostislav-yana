# Ростислав и Яна · 30 января 2027

Свадебное приглашение: интерактивная фотооткрытка, галерея, таймер, программа дня и анкета гостя.

Файлы `index.html`, `style.css`, `app.js` и `config.js` — сайт для GitHub Pages. Фотографии встроены в страницу и стили, поэтому дополнительных папок для них не требуется.

`backend-worker.js` — отдельный серверный обработчик: сохраняет анкеты в закрытом R2 и отправляет их в Telegram. `telegram.js` — отдельный исходник отправки уведомлений, уже встроенный в обработчик.

GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).

В `config.js` указывается только публичный HTTPS-адрес обработчика. Токены и ключи в этот файл не добавлять.

Секреты обработчика: TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID, ADMIN_KEY. Настройки: TELEGRAM_REQUIRED=true, ALLOWED_ORIGINS=https://denistimer.github.io. Привязка закрытого хранилища: BUCKET (R2).

Проверены: мобильная версия, галерея, анкета, защита закрытого списка ответов, повторная отправка, валидация и формат Telegram-уведомления. Реальную доставку в Telegram нужно проверить после подключения бота.
